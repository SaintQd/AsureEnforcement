## AsureEnforcement

Плагин, реализующий базовые возможности охраны порядка на сервере уполномоченными игроками. Добавляет функционал оглушающих
дубинок, наручников, конвоирования игроков и заключения их в тюрьму. Каждый предмет плагина или возможность регулируется пермишенами,
позволяя при необходимости создать отдельную группу игроков, обладающую полномочиями правоохранения.

---

## Модули и возможности

- **Дубинки**: Предмет, оглушающий игрока на некоторое время, если при нанесении удара у игрока меньше указанного процента здоровья.
оглушённый игрок не может двигаться и совершать какие-либо действия. Во время оглушения игрок может быть закован в наручники.
Оглушение имеет кулдаун и не может совершаться несколько раз последовательно без задержки.\
Любой предмет может быть дубинкой при наличии необходимого свойства PersistentDataContainer.
- **Наручники**: Предмет, которым можно заковать игрока, отключив ему возможность как-либо взаимодействовать с блоками. На задержанным
игроком может отображаться текст (`ЗАДЕРЖАН` в стандартном варианте). Закованный в наручники игрок может быть конвоирован. 
Освободить игрока от наручников можно с помощью ключа от наручников.\
Если задержанный игрок отойдёт на определённое расстояние от игрока, заковавшего его в наручники, или будет регулярно нажимать ЛКМ, начнётся процесс
освобождения от наручников, в результате которого игрок может сам сбросить с себя наручники.\
Любой предмет может быть наручниками или ключом при наличии необходимого свойства PersistentDataContainer.
- **Конвоирование**: Нажав ПКМ по закованному в наручники игроку, заковавший его игрок может начать процесс конвоирования. Между
обоими игроками появится линия из частиц, а закованного игрока начнёт регулярно подтягивать к заковавшему его игроку.
- **Тюрьма**: Регион можно обозначить как подходящий для размещения игроков в тюрьму (Jail) флагом WorldGuard `enforcement-jail-region`. Для закованного в наручники
игрока, находящегося в пределах такого региона, можно выполнить команду, которая позволит посадить игрока в тюрьму с названием, обозначенным
в значении указанного флага.\
Примечание: данный плагин сам по себе не реализует функционал тюрьмы и позволяет лишь определить, в тюрьму с каким названием может быть
посажен игрок. Функционал тюрьмы должен быть реализован подходящим сторонним плагином.
- **Кусачки**: Предмет, позволяющий освободить другого игрока от наручников. Отличается от ключа от наручников другим пермишеном
на применение, а также одноразовостью - кусачки пропадают при использовании.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib. Путь до артефакта должен
выглядеть следующим образом относительно папки проекта: `../AsureLib/build/libs/AsureLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
